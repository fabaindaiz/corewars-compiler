A static rule calibrated against real runs is right on its calibration cases and still wrong on layouts nobody fed it. After calibrating, ask an adversary to build inputs that break the rule before it ships: the same move as an adversarial generator per promise, applied to a static analysis or a warning instead of a property test. It overlaps the queued one-adversarial-generator-per-promise.

## Evidence

One carrier. A static warning that predicts when a program overwrites its own code was calibrated against runs of five programs, and agreed with each run. A fresh-context reviewer then built, in minutes, two layouts it got wrong: a pointer held in the loop's own jump instruction, written every lap (a miss), and a pointer rewritten before its loop started (a false warning and a miss). Both became tests, each seen to fail first.
